WHY I PICKED IT

“What’s still unpaid?”
should be easy to answer.

I wanted to understand how a small business keeps track of clients, invoices, payments and transactions without spreading the same information across several files.

I built a Streamlit workspace with a PostgreSQL database, invoice generation, spreadsheet review and collection priorities. The current interface uses deterministic rules and calculations. It does not call an LLM.

My focus was keeping balances consistent and checking incoming data before it changes the records.

HOW IT WORKS

A database underneath.
A clearer workspace on top.

I use Python and Streamlit for the interface, PostgreSQL for persistent records and Pandas for tabular imports. The app can generate PDF invoices using ReportLab.

The import workflow maps spreadsheet columns and flags invalid rows for review. Payment records change the outstanding balance, while the analytics page calculates collection priorities from invoice data.

Although some source modules use “AI” names, the analysis wired into this version is rule-based. The AI Advisor navigation item is still a placeholder; I don’t count it as a finished feature.

THE LIMIT OF THESE CHECKS

Payment writes were checked through the database layer. The browser walkthrough checked rendering and initial execution, rather than every create, edit and delete action.

WHAT WENT WRONG

Labels and screenshots
aren’t enough on their own.

I had to distinguish finished navigation from modules that existed in the repository but weren’t wired into the app. I made that distinction explicit in the documentation.

I also checked imports with deliberately awkward data. A spreadsheet that looks tidy can still contain duplicate invoices, missing relationships or invalid amounts.

The synthetic data and disposable database made it possible to check writes and exports without using real business records.

I’m learning why finance tools need careful data relationships, repeatable imports and clear payment states. A dashboard is only useful if the records underneath agree.
